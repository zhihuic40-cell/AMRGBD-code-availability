# Sensitivity Analysis: Input Data Uncertainty Propagation

This folder contains the Monte Carlo sensitivity analyses that propagate GRAM input data uncertainty into the age–period–cohort (APC) and Bayesian APC (BAPC) models. Results are reported in **Supplementary Tables S8–S9** of the manuscript.

## Overview

The primary APC and BAPC analyses used GRAM point estimates as inputs. Because the full set of GRAM posterior draws is not publicly available, we performed Monte Carlo sensitivity analyses to assess whether input data uncertainty materially affects the conclusions.

**Approach:** For each age–year cell, a log-normal distribution was fitted to the reported point estimate and 95% uncertainty interval. 500 perturbed datasets were generated by independently sampling from these distributions, and each was analysed through the full APC or BAPC pipeline.

## TableS8 — APC Net Drift Sensitivity

**What it does:** Re-runs the NCI APC analysis 500 times, each time with a different perturbed input dataset, and reports the median net drift with 2.5th–97.5th percentile Monte Carlo uncertainty intervals.

**Method:**
1. `draw_utils.R` — Fits a log-normal distribution to each cell's point estimate and 95% UI; generates 500 independent draws.
2. `prepare_draw_inputs.R` — Constructs 500 complete input matrices in the format required by the APC tool.
3. `run_table1_draws.R` / `run_table2_draws.R` — Executes APC analysis for each draw (pathogen-specific and regional, respectively).
4. `summarize_draw_results.R` — Computes summary statistics across 500 draws.
5. `run_all_draws.R` — Orchestrates the full pipeline.

**Entry point:** Run from the repository root:
```r
source("code/Sensitivity/TableS8/run_all_draws.R")
```

**Output directory:** `results/Sensitivity/TableS8/`

## TableS9 — BAPC Counterfactual Sensitivity

**What it does:** Re-runs the Bayesian APC (BAPC-INLA) counterfactual analysis 500 times with perturbed historical input data, and reports the median relative change with 2.5th–97.5th percentile uncertainty intervals.

**Method:**
1. `TableS9_common.R` — Shared log-normal draw generation, BAPC model fitting, and result extraction functions.
2. Each `TableS9_<Pathogen>_<Metric>.R` script runs the full 500-draw pipeline for one pathogen × metric combination.

**Entry point:** Run from the repository root, e.g.:
```r
source("code/Sensitivity/TableS9/TableS9_GNB_Associated.R")
```

**Output directory:** `results/Sensitivity/TableS9/`

## Note on Reproducibility

The **TableS8** scripts use the `easyGBDR` R package, a validated commercial implementation of the [NCI Age-Period-Cohort Web Tool](https://analysistools.cancer.gov/apc/) methodology. We verified that `easyGBDR` produces identical results to the NCI Web Tool for all primary analyses.

Because `easyGBDR` requires a licence, there are two ways to verify the sensitivity results:

1. **Check pre-computed outputs** — The summary results used to generate Supplementary Table S8 are provided in `results/Sensitivity/TableS8/`.
2. **Manually verify individual cases** — Any single draw can be reproduced by entering the perturbed input data into the freely available [NCI APC Web Tool](https://analysistools.cancer.gov/apc/).

The **TableS9** scripts depend only on freely available packages (`INLA`, `tidyverse`) and are fully reproducible.
